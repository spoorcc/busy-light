# Contributing

This project follows a documented engineering process. Read these first:
1. [`docs/process/README.md`](docs/process/README.md) -- lifecycle, gates, definition of done
2. [`docs/process/planning-egm.md`](docs/process/planning-egm.md) -- how we plan (design doc, then review, then code)
3. [`docs/standards/`](docs/standards/) -- coding, hardware, mechanical and writing standards

Short version: **specification before implementation; every code change comes with a test; hardware is verified by
simulation and analysis; decisions are recorded; every change goes through a pull request using the checklist.**

Small fixes (typos, obvious bugs with an approved requirement) can skip the design doc but still need a test.
Open an issue to discuss larger changes before you write code.
