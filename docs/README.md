# Docs

Start with [`process/README.md`](process/README.md) -- it defines the lifecycle,
gates, IDs and review rules that all other documents follow.

| Folder | Contents |
|--------|----------|
| `process/` | Lifecycle, document control, EGM planning, verification strategy, definition of done |
| `requirements/` | Needs, system, SW, HW, MECH requirements |
| `architecture/` | System architecture, interfaces, detailed design |
| `decisions/` | ADRs (immutable once accepted) |
| `standards/` | Coding standard, writing standard (ASD-STE100 based), HW and mechanical DFx rules, deviation register |
| `regulatory/` | CE/market-access: applicability assessment, compliance matrix, technical file (dossier) |
| `user/` | User documentation (manual, quick start, safety) |
| `risk/` | Risk register / FMEA |
| `verification/` | Test plans, test reports, traceability, release records |
| `reviews/` | Formal review records |
| `plans/` | Working plans and schedules (not controlled requirements) |
| `journal/` | Dated notes on work without a controlled home (sourcing checks, tool findings); not evidence of approval |
| `templates/` | Templates for all of the above |
| `diagrams/` | Diagram sources (PlantUML, Mermaid, WaveDrom) and generated SVG |
| `images/` | Photos and screenshots only |
