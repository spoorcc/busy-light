# Engineering Standards

Binding design rules per domain. They are inputs to requirements and **review checklists**.
Deviations are never silent: record them with `docs/templates/deviation.md` (ID `DEV-nnn`
listed in `docs/standards/deviations.md`), with justification, risk assessment and approval.

| Domain | Document |
|--------|----------|
| Software (C / Zephyr) | [coding-sw.md](coding-sw.md) |
| Hardware (KiCad / PCB) | [design-hw.md](design-hw.md) |
| Mechanical (FreeCAD) | [design-mech.md](design-mech.md) |
| Documentation (ASD-STE100 based) | [writing.md](writing.md) |
| Diagrams as code (PlantUML, Mermaid, WaveDrom) | [diagrams.md](diagrams.md) |

Standards names below are referenced, not reproduced. MISRA documents are copyrighted and must be
obtained by the project (they are not stored in this repo).
