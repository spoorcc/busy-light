# Journal

Dated notes on work that has no controlled home: sourcing checks, tool findings, dead ends, working assumptions.
The journal is **not** evidence of approval and **not** a controlled document. It never changes a requirement,
an ADR or a risk.

Rules:

- One file per topic and day: `YYYY-MM-DD-topic.md`. Add new files; do not rewrite old ones (add a dated
  correction instead).
- Say what was done, what was found, and what was **not** checked. State the date and the source of every number.
  Mark unverified values as unverified.
- When a finding affects a requirement, ADR, risk or test, open the change in that document and link back here.
  Move durable evidence to `docs/verification/reports/` or `hw/sim/`.
- Reference IDs (for example HW-010) in the text. Do not start a heading with an ID: the traceability check reads
  such headings as definitions.
